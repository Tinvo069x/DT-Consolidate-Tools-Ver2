  • 1Reads the first worksheet from each file; accepts original Qty, four-file XP, and C08/V15 Week-Month layouts.
  • 2Original layouts use headers in row 2. C08/V15 use headers in row 1, data from row 2, and map Material → LD Part, Material Description → Des, Reorder Point → ROP.
  • 3Original Qty or repeated-Type exports use dates across columns. C08/V15 files pivot their Week-Month rows and four measure columns into the same four-Type output.
  • 4Timeline dates become d-mmm-yy text headers; date cells are preserved and exported as d-mmm-yy.
  • 5Outputs the standard 18 fixed columns in the requested order. Unsupported source columns are dropped; unavailable target fields remain blank.
  • 6Places Timeline columns after fixed columns and sorts them by date from oldest to newest.
  • 7For the new layout, fills missing Type rows to ensure four rows per LD Part. Removes blank LD Part / Type rows; sorts by LD Part A→Z, then Type A→Z.
  • 8When ROP is 0, sets all Timeline values to 0 for the row whose Type is 01 Demand FCST-XYS.
  • 9Recalculates 03 Acc Variance by LD Part: first Timeline = Stock-0007 − 01 Demand − 01 Demand FCST-XYS + 02 Supply; each later Timeline uses the previous Acc Variance balance.
  • 10On Excel / CSV export only, blank Timeline cells are changed to 0 for 01 Demand, 01 Demand FCST-XYS, and 02 Supply. Preview and calculation logic remain unchanged.
